Make a new report from matching CSV exports

Use Google Forms CSV exports with the same columns. The tool combines files into one report, preserves filename-based cohorts, and never uploads the response data.

Select one or more CSV files exported from the same form. Quoted comments and line breaks are supported.

Private by design. Processing happens in this browser. Refreshing or closing this page clears the uploaded data.

What makes a CSV compatible?

Every selected file must have the same header row. The tool treats columns containing only 1–5 values as rating questions, recognizes a timestamp column when present, and recognizes a clearly named or likely free-text feedback column when present.

It is optimized for Google Forms exports like the published report. It reports missing values rather than silently converting them to a score.

Question scores

Means use all available responses to each item. The bar uses the full 0–5 scale.

Filename-based cohorts

Cohort labels come from filenames and are descriptive only—not departments or facilitators.

Additional profile fields

Categorical fields outside the rating scale—such as department, team, job level, location, or AI-tool questions—are summarized when present.

Full question distribution

Ratings are classified as positive (4–5), neutral (3), and negative (1–2) for analysis.

Written feedback — local review
